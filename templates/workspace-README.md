# Bounty workspace

Created by [OpenCode Red](https://github.com/danielvaldess/opencode-red).

One folder per program. Start a new one with:

```bash
bbnew <program>
cd <program>
```

Then:

1. Fill `scope.md` from the program page.
2. Open OpenCode in that folder.
3. Run `/hunt <target>`.

`AGENTS.md` contains the rules and the workflow; read it before testing.
